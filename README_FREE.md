# SkinSmart AI — Free Starter

This is a zero-cost front-end demo for the SkinSmart AI hackathon idea.

## What works in this demo
- Responsive skincare website UI
- Local photo preview (the photo is not sent anywhere)
- User-selected skin type and general product guidance
- Sample product cards and clearly labelled sample prices
- Lipstick colour explorer and undertone guide

## What is not connected yet
- The photo is NOT analysed by AI. Photo upload only previews the image locally.
- Product prices and store labels are fictional demo data, not live offers.
- No account/login, checkout, or real YouCam API connection is included.

## Open on your computer for free
1. Download and unzip `SkinSmartAI_Free_Starter.zip`.
2. Double-click `index.html` to open it in Chrome or Edge.
3. Try the skin-type selector, recommendations, and shade explorer.

## Publish a free demo with GitHub Pages
1. Create a public GitHub repository (for example, `SkinSmartAI`).
2. Upload `index.html` to the repository's root folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to provide the published website URL.

## Keeping costs at ₹0
Do not enter payment details or subscribe to a paid API. Only add YouCam or live-price integrations if an officially available free tier is confirmed. Never publish API keys in HTML or GitHub. If a real API is added later, keep its key on a server in a private environment variable.

## Important honesty/safety notes
This is a prototype, not a medical device. A face photo alone cannot reliably establish skin type or diagnose a condition. Product suggestions are general information. Sample prices must not be described as live prices.
